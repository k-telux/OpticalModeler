# 六组完整的用户—Agent 交互与交付案例

[English](WALKTHROUGHS.md) · [案例索引与真实公开图](README.md)

以下对话均为根据项目工作和已公开示例整理的教学性改写，不是逐字聊天记录。B–E 使用一致的功能别名，抹去关键仪器身份、实际坐标和运行参数；不公开实验室照片、私有 Blender 或原始审查记录。案例描述的是完成需求的过程与交付边界，2.0 发布没有重新生成这些模型，也没有新增盲测或物理资格认证。

## A．从二维示意图到可查看的三维最终结果

**输入：** 已公开的 G1/G2 光路图。**任务：** 按图重建整机，之后在独立副本做展示。**交付：** 整体/俯视图、接口证据和一致的验收说明。

**用户：** 按这张图生成完整光学平台，要包括 sample/collection、fiber coupling 和两路 photon counting。给我清楚的整体图和俯视图。

**Agent：** 我会先逐条整理有向支路，把每个节点映射到器件、真实端口和支撑链。自由空间光、光纤和电气探测连接分别处理；替代件或自建件会注明来源与限制。

**用户：** objective 的方向不对，fiber coil 应该直接放主桌面，还有几个 clamp 相交。先修这些，不要继续美化。

**Agent：** 已把这些问题记录到对应对象族，冻结上一批交付。先验证一套大入口朝向自由空间、真实肩面/座孔固定并连续到 FC 接口的 launch；通过后再传播。光纤会连同两端一起移动，最后重开保存文件检查所有夹具和邻居。

**用户：** 现在保持已接受的几何，做主图/封面风格的展示，不要改光路。

**Agent：** 我会另存展示副本，保留明亮接口图。最终会检查实际输出尺寸、逐图可读性，以及保存文件中的几何保持情况，再交付。

**最终产出：** 可以直接查看已公开的[最终 hero 预览](../g1g2/output/v18_nature_hero_graphite_final_4k_preview.jpg)、[标注俯视预览](../g1g2/output/v18_nature_complete_top_annotated_final_4k_preview.jpg)和[脱敏验收记录](../g1g2/evidence/v18_nature_final_acceptance.json)。历史记录报告 `PASS_V18_NATURE_FINAL_VERIFIED`、重开、图像 QA 和三方展示审查。仓库提供的是压缩预览，未包含原始 16-bit master 或私有可编辑场景。

**可复用经验：** 复用语义、端口、支撑和证据流程。若用户要求“同等质量的另一种测量”，应从空场景和新拓扑开始，不能复制旧整机后直接改名，也不能继承旧 PASS。

## B．基于照片重建，硬件信息不完整时也交付可审阅模型

**输入：** 私有标注照片、功能示意图、用户要求保留的基线。**别名：** `SOURCE_A`、`SOURCE_B`、`DELAY_STAGE`、`SAMPLE_MODULE`、`SPECTROGRAPH`、`DETECTOR_BACK`。**交付：** 一个完整可编辑的 optics-only 审阅版本。

**用户：** 保留已经接受的建模规则，按实际照片重建 pump/probe。大仪器的外形大致对，但位置和朝向不对，先完成一个我能手动检查的模型。

**Agent：** 我会冻结原文件，在新修订里工作。照片/用户确认的实装身份、厂家候选 CAD、照片估计的尺寸会分开记录；先看完已有视角，再问影响建模的关键未知问题。照片里的电缆不自动扩大 optics-only 范围。

**用户：** 两组升高/降低反射镜实际都固定在同一块竖直面包板上，你现在只画了没有真实安装的镜臂。

**Agent：** 我会把镜架与 holder 接到这块板及其支架、脚、桌孔的连续支撑链上，不会只在镜臂后面补装饰板。大型仪器移动时也会一起移动端口、支撑和紧固件，并重新连接受影响光路。

**用户：** 今晚没有剩下的焦距和型号，先把这一版完成，之后列出去 lab 要核对什么。

**Agent：** 我会完成已授权的审阅候选，不猜实际后缀和光学处方。未知内部光路保留为功能黑箱，指南会区分模型测量、图纸尺寸和现场实测。

**Agent，完成检查后：** 已重开保存模型，检查本轮受影响光线、支撑和邻居范围，并查看实际整体、俯视和接口图。模型保存了清楚的打开视图；实际 UI 输入如果无法验证，会单独保留 unknown，不能用渲染代替交互验证。

**最终回复示例：** “照片布局审阅包已完成：可编辑模型、完整光路视图、观看说明与现场核对清单。原基线保留。实际型号后缀、隐藏安装、透镜处方、螺纹/预紧与整机性能仍待确认，因此是 `PARTIAL_SCOPED`，物理通过标志保持 false。”

**交付结构：** 私有 `Delivery/Review.blend`、最终 `Images/`、观看/测量指南与范围/哈希清单。这些是交付命名示例，不是本仓库可下载的实验室文件。

**下次现场优先项：** 带尺拍摄不可读标签和安装接口；测量光轴高度、relay 间距、detector/adapter 配置。用户要求先交付时，完成审阅候选后再汇总这些问题，不用未知信息阻止所有独立工作。

## C．“紧凑一些”不是重新设计光路：从用户否决到正确平移

**输入：** 已接受的下层支路、固定的上层接入点、标注箭头。**任务：** 有边界的布局修订。**主要风险：** 把局部紧凑请求扩大成光路内部重排。

**用户：** 把这一组光源支路移近上层平台，四片平面镜可以调位置，竖板按图转向，但光源和前后器件关系要保留。

**Agent：** 我会先锁定源组内部相对向量、光学顺序、水平 conditioning 方向和已接受的上层接入点，列出四镜和支撑可动自由度，再测桌边/板体净空。

**用户：** 这版错了，你改了光路构成，还移动上层反射镜。我只是想让源组平移，让板子适配固定的上层光路。

**Agent：** 之前的几何检查没有证明你的意图。我会恢复接受基线的上层完整位姿和源组内部关系，保留否决原因，只改授权自由度。新纠正覆盖错误布局，不影响无关基线。

**用户：** 锁定原版上层位置。板和板上两镜允许沿固定入射轴移动，法线仍朝外。

**Agent：** 我会沿这条轴整体移动板和两镜，保持高度、法线和组内关系，重新落到真实孔位，不假设平台开新通光孔。下一轮同时检查固定端点和源组两两向量。

**用户：** 器件关系现在正确，但整体平移还不够。除了竖板，把下层这一支路全部放到上层平台投影下面；必要时可以延长上层板、改变大支柱位置。

**Agent：** 这次新增了完整覆盖要求。我会检查器件连同支撑的实际 footprint 与上层板投影并集，做一次共同平移，仅使用已允许的镜位和支柱例外。只把中心点移进投影不算完成，移动族之间的碰撞、柱脚/螺钉孔位也会检查。

**Agent，完成检查后：** 声明范围内的完整器件/支撑投影已覆盖，保存模型中的受影响状态光线没有新增意外遮挡。下层与升高图已看实际成图；被平台挡住的视角改为互补角度，没有隐藏硬件来制造结果。

**最终回复示例：** “整体平移和平台覆盖已落实，交付新工程模型、独立展示副本、最终图和修订说明。旧接受文件保留。源组内部关系和上层光学位姿已分别核对；真实 retention/preload、全载荷与实际处方仍未验证，保持 `PARTIAL_SCOPED`。”

**防回归检查：** 固定上层完整位姿、刚体内部向量、准确镜数/顺序、水平段方向、完整 footprint 覆盖、授权支撑例外。用户否决的意图不能由数值诊断 PASS 抵消。

## D．外壳太白、反射太强：只做展示副本

**输入：** 已接受模型、已有相机组、外壳发白截图。**任务：** 材质与打光。**交付：** 独立展示副本及所有受影响视角的新图。

**用户：** 模型已经正确，power detector 外壳太白，source 顶盖大片反光。整体稍暗一些，突出目前光线，不要重新改模型。

**Agent：** 我会冻结原文件，另存展示副本。先查真实外壳槽位、shader 和共享用户；感光面、镀膜、束线位置/颜色/半径、可见性与已有相机保持。

**Agent，诊断后：** 名叫 black 的材质底色实际很浅，顶盖材质又与其他对象共用。只给指定外壳/顶盖槽复制独立材质，再用局部 shader 和打光压下 glare，避免影响探测面和其他器件。

**用户：** 这一张预览的色调可以，不要继续做配色变体。

**Agent：** 我会保留这次选择。最终渲染前比较保存后的 source/candidate，包括几何连接、法线、实际属性、modifier、语义 metadata 与两态；仅对象数量一致不够。

**Agent，完成检查后：** 受保护几何与相机保持，差异只在声明的外壳材质和灯光。八个受影响视角已重新渲染，实际解码核对尺寸/位深并逐张查看，下层器件轮廓和支路仍能辨认。

**最终回复示例：** “灰色展示包已封存：新可编辑展示文件、八张原生 3840 × 2400 RGB16 图、观看说明和 manifest。原工程/展示文件保留。本轮只改变外观，不增加物理资格。若环境无法截取最终回复窗口，会明确报告 `reply_visual_confirmation=incomplete`。”

**图像来源原则：** 仅一台相机变化时，其余图可以在保留原 producer 并证明完整依赖保持后复用。重新打光/改色会影响图像依赖，受影响视角需要新渲染；不能把旧图清单改成新 Blend hash 来伪造新出图。

## E．已装背端、拟装侧端与漏画快门：让状态可解释

**输入：** 现有仪器/照片、厂家配置资料、已接受灰色展示。**别名：** `SPECTROGRAPH`、`DETECTOR_BACK`、`DETECTOR_SIDE_PROPOSED`、`ENTRANCE_SHUTTER`。**任务：** 局部参考重建；不认证制造或真实硬件。

**用户：** 保留这一版。光谱仪实际有一个入口、两个出口，我们背端已有 detector，侧端计划加 camera，你也漏画了入口外置 shutter。

**Agent：** 我会冻结接受的机壳、入口、背端 detector 位姿和外观，先明确厂家端口名称与当前世界坐标的对应。侧端会标为拟装；adapter、焦面和 shutter 未知部分保留参考身份。

**Agent：** 这版需要加入明确标注的拟装 detector 参考，还是只核对并预留接口？

**用户：** 加入拟装参考模型。

**Agent：** 我会补真实侧壁开口、参考 receiver/支撑和入口快门的 OPEN/CLOSED 几何。配置资料支持端口选择，不会画成同时分光；未确认的内部传输保持黑箱。

**Agent，第一次重开后：** 中心轴到达窗口，但这不能证明整个安装接口。有限截面发现参考螺钉入口残盖/轮廓不匹配，需要局部修正，再从入口测到孔底；名义半径和 bbox 都不足以排除问题。

**Agent，修正后：** 模型记录五个明确状态：两个保留的背端开启运行条件、拟装侧端开启、背端关闭和拟装侧端关闭。每态刷新 evaluated transform/visibility，分别绑定 selector、shutter 和光线证据。关闭时光轴止于标注的闭合包络，两出口均不激活；无关旧状态和灰色外观保持。

**最终回复示例：** “三端口/快门局部审阅包已完成：可编辑状态模型、总览、背/侧端、接口和快门图，附使用说明及测量清单。背端是现有，侧端明显标为拟装。有限参考接触已检查，实际 shutter 型号、adapter、焦面、密封、螺纹/预紧与完整承载/性能仍未验证，物理通过标志为 false。”

**下一步有用信息：** 实际端口选择配置、shutter 标牌与安装、计划 camera 后缀/冷却、adapter 接口和焦深。精细参考模型不能通过外观细节悄悄升级成已装硬件。

## F．程序退出成功但审计失败：交付真实断点，而不是旧 PASS

**输入：** 整机运行的退出记录、审计文件和 ledger。**任务：** 恢复证据链。**交付：** 合法当前记录，或可复现 blocker/恢复点。

**用户：** 后台程序正常退出了，把 workflow 做完并打包。

**Agent：** 我会检查新鲜 report 和实际打开的文件身份。退出码 0 不能证明所需审计；report 要绑定 run、attempt nonce、runtime/helper、实际保存文件，以及要求的 commit/reopen 证据。

**Agent：** 当前 report 缺失或身份不一致，门状态是 `BLOCKED_AUDITOR_EXECUTION_FAILURE`。以前只有 generation 的文件不能补授 audit credit。我会保留失败记录，诊断路径，并保存具体 blocker 和下一步动作。

**用户：** 修复 report 路径，在同一 run 继续，保留有效上游证据。

**Agent：** 我会在相同 writer/来源谱系内使受影响门失效，只重做依赖检查。如果新增 ledger event 的 ID 重复或时间戳不合法，要在改写事件/状态文件之前由候选 replay 拒绝。

**Agent，软件检查后：** 回归检查确认非法日期、重复/空 ID 不改变原有两份持久文件；有效 record/invalidate 仍能重放。这证明提交前验证，不声称两文件跨崩溃原子性，也不是新的模型物理证据。

**最终回复示例：** “ledger 软件修正已验证。如果模型审计仍无法生成匹配的当前证据，交付包括冻结候选、结构化 blocker、已完成上游门与可复现下一条命令，物理/最终发布标志保持 false。拿到真实匹配审计后，只能按其实际范围前进。”

可运行的 [ledger 测试](../../tests/test_workflow_ledger.py)与[运行模式验证测试](../../tests/test_validation_runtime.py)证明软件边界；不能替代 Blender 几何、真实 UI 交互或实机测试。
